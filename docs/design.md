# Antigravity Lean v0.1
Audience: Google AI Ultra family members using Antigravity App and agy CLI.
The user requested immediate deployment, public GitHub publication, and a local
synchronized repository at F:/OpenSource/antigravity-lean.

Ship a dependency-free Node >=20 terminal wizard and native plugin. Windows
launchers: install.cmd / install.ps1; macOS/Linux: install.sh. Global/project
scopes, balanced/gemini-first/claude-first profiles, editable model labels.
Separate Gemini and Claude/GPT recommendations according to the supplied UI.
Do not claim live quota access, family-wide usage aggregation, automatic model
switching, or guaranteed savings. Baseline limits and shared AI credits differ.

One concise always-on hygiene rule; planning/handoff in an on-demand skill.
Read-only flash explorer only when delegation is worthwhile.
Preview before confirmation; noninteractive writes require --yes. Dry runs write
nothing. Refuse unmanaged targets, edits on update, invalid manifests, and symlinks.
Stage then rename updates with rollback and retained backup. Uninstall only
unchanged tracked files; preserve user edits/extras. Doctor checks file integrity.
Do not install into maintainer's real global settings.

Alternatives: shell-only installers duplicate cross-platform filesystem logic;
hosted wizards need a download bridge. Local Node wizard is portable and offline
after download. GitHub checkout/ZIP is primary; no npm account required.
